# Вопросы к ТЗ: статусы, rollup, группы метрик

К документу: `PROMPT_STATUSES_ROLLUP_METRIC_GROUPS.md`.

ТЗ в целом ясное: три оси (полосы / rollup / группы) разделены, DoD проверяемый, порядок работ логичный. Ниже места, где без решения можно разъехаться при реализации.

---

### 1. ADVISORY + «жёсткий» порог — что на листе?

Самое спорное место. Сейчас в ТЗ рядом:

- серая зона advisory → **INFO**;
- выше fail → **INFO** *или* лист-**WARN** без rollup;
- DoD для throttle 2% → INFO (или WARN только в листе).

Нужно зафиксировать **один** вариант для всех ADVISORY banded-проверок, например throttle:

| value | статус **на карточке** | влияет на host/group? |
|-------|------------------------|------------------------|
| ≤1 | OK | нет |
| (1; 10] | ? | нет |
| >10 | ? | нет |

Варианты: всегда потолок **INFO**; или серая зона INFO, а >fail — **WARN/FAIL только на листе**. Что выбираем?

---

### 2. Rollup у конкретных плагинов

Явно BLOCKING: CPU/RAM usage, leak, restarts.  
ADVISORY: «лёгкий throttle».

Уточнить для каталога по умолчанию:

- **CPU throttling > …** — точно ADVISORY?
- **Throttling trend ↓** — BLOCKING (рост = серьёзно) или ADVISORY?
- **TCP established / time_wait** — остаются BLOCKING + single threshold, или сразу ADVISORY как в примере «шумные TCP»?

---

### 3. ADVISORY + NO_DATA / SKIP

В aggregate родителя идут только BLOCKING. Значит, если у deployment все проверки ADVISORY и одна дала NO_DATA/SKIP — родитель всё равно **OK**? Или NO_DATA/SKIP с advisory всё же учитывать?

---

### 4. Summary-карточки

Добавляем счётчик Info. Куда в ряд:  
`Fail | Warn | Info | No Data | Skip | OK` — ок, или Info в другом месте?

---

### 5. Иерархия K8S

Сейчас: `K8S → ns → deployment → проверки` (уровень value схлопнут).  
После ТЗ: `… → deployment → metricGroup → проверки` — верно? (без возврата пустого value-уровня)

---

### 6. VM CPU и полосы

Сейчас VM CPU — **instant на `to`**, не max за `from–to`. DoD «CPU 85% → WARN» относится к этому значению «на конец окна» — так и оставляем, без смены на max за период?

---

### 7. Мелочи (если есть предпочтение)

- Цвет INFO: скорее **синий** или серо-нейтральный?
- Banded только для `>` (CPU/RAM/throttle) — `≥` / `<` пока не нужны?
